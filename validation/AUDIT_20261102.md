## Repairs

- The former audit visited theorem roots only. It now visits every project
  declaration, including unused axioms and data definitions that could contain
  an admission. Private and generated declarations and project backports in
  library namespaces remain included.
- Full-import coverage was checked only among modules already loaded. The
  source checker now compares all mathematical files on disk with both the
  build aggregator and the audit's `import all` list, rejecting orphan, stale,
  or duplicate entries. The current 396-module tree had no omissions.
- `scripts/verify-clean.sh` now gives one reproducible clean-project build:
  verify all nine dependency Git revisions and clean tracked sources; remove
  the entire project build directory; rebuild the library and aggregate
  solution; run the all-declaration audit; build `Challenge` separately.
- Build CI runs that procedure after setup and retains its complete log.
- Stale comments in `Main.lean`, `ProvedMain.lean`, `SpectralMain.lean`, and
  `CanonicalSpectralCandidate.lean` now distinguish conditional intermediate
  interfaces from the later unconditional endpoint. README badges select the
  active branch.

## Scope limit

The manuscript's uniqueness classification among **all convex maximizers**
is outside the Lean final theorem. Marked radial rigidity is a narrower
proved result. Full gradient-functional stability is likewise not asserted.
The present audit preserves these explicit boundaries; it does not claim to
have formalized every statement in the paper.

The only deliberate proof placeholder is the reference theorem in
`Challenge.lean`. It is built separately and never imported by `Solution`.
The proof development and aggregate solution admit only `propext`,
`Classical.choice`, and `Quot.sound` as axiom dependencies.
